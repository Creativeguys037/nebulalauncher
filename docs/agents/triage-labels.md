# Triage Labels

技能用五个规范**状态角色**说话。本文件把这些角色映射到本仓库议题跟踪器实际使用的标签字符串。
全部沿用默认字符串，不另建同义词。

| Label in mattpocock/skills | Label in our tracker | 含义                                   |
| -------------------------- | -------------------- | -------------------------------------- |
| `needs-triage`             | `needs-triage`       | 需要维护者评估                          |
| `needs-info`               | `needs-info`         | 在等报告者补充信息                      |
| `ready-for-agent`          | `ready-for-agent`    | 已完全写清楚，可交给 AFK 代理            |
| `ready-for-human`          | `ready-for-human`    | 需要人来实现                            |
| `wontfix`                  | `wontfix`            | 不会被处理                              |

类别角色沿用 GitHub 现成的同名标签：`bug`（有东西坏了）、`enhancement`（新功能或改进）。

每张分诊过的议题恰好带一个类别角色和一个状态角色。状态角色互相冲突时，先把冲突标出来，问过维护者再动。

当某个技能提到某个角色（例如「apply the AFK-ready triage label」），用本表右侧对应的标签字符串。

右侧一列按本仓库实际词汇编辑；改这里，不要改技能。
