# Nebula Launcher v1.1.1

v1.1.0 之后的修复版，2026-11-01 发布。修的是皮肤页「云端衣柜」的登录崩溃：在便携（裁剪）发布里，保存过皮肤站账号的机器点「登录」会让整个启动器进程退出。安装、启动与其他页面未改。

## 一、本版修了什么

**票 #62：皮肤站登录崩溃（v1.1.0 / Win11 / .NET 8）。**

现象：皮肤页 → 云端衣柜，站点已有保存的账号时点「登录」，启动器直接崩溃；自动登录路径则只显示「读取本机保存的皮肤站账号失败，请重新登录。」。

根因：`src/NebulaLauncher.App/Skinning/CloudClosetClient.cs` 的登录请求体用 `JsonSerializer.Serialize(new Dictionary<string, object?>{...})` 拼装，没有传 `JsonSerializerOptions`。便携发布带 `PublishTrimmed=true`，System.Text.Json 的反射解析器被关闭，这一行必抛 `InvalidOperationException: Reflection-based serialization has been disabled for this application.`。自动登录路径捕获了它，只留一条 WARN；手动点「登录」走 `CloudClosetViewModel.LoginCoreAsync`，那里只有 `finally` 没有 `catch`，异常穿透 `AsyncRelayCommand`，而 App 层没有全局未处理异常兜底，进程随即退出。

修复：

1. 登录请求体改为具名 `LoginRequest` record（`identification` / `password` / `remember` 字段名用 `[JsonPropertyName]` 钉住），经 `CloudClosetRequestJsonContext` 的 source-gen 元数据序列化。
2. 同一文件里另外两处 HTTP 请求体一并改掉：应用材质（`Dictionary<string,int>`）与清除材质（`ClearTextureRequest`）。
3. `src/NebulaLauncher.App/Skinning/MojangSkinClient.cs` 的「切换披风」请求体同样改为 `MojangSkinRequestJsonContext` 的 source-gen 元数据。
4. `CloudClosetViewModel.LoginCoreAsync` 补边界 `catch`（不吞取消异常）：写「皮肤站登录异常」日志，界面显示「皮肤站登录过程出错：<原因>」，不再让异常穿透命令。
5. 新增回归测试 `tests/NebulaLauncher.Tests/AppSkin_CloudClosetLoginFallbackTests.cs`：登录接口返回 HTML（会话失效、风控页等）时，命令不抛、状态未登录、错误文案可见。

## 三、安装与体积

体积在本机 win-x64、Release 配置下由 `build.ps1 -Publish` 构建、`tar -a -c` 打包后实测（2026-11-01，发布号 `v1.1.1`）。数字随 .NET 运行时版本与构建机变化。

| 附件 | 形态 | 实测体积 | 文件数 | 前提 |
| --- | --- | --- | --- | --- |
| `NebulaLauncher-v1.1.1-win-x64.zip` | 框架依赖 + 单文件，原生库外置 | 压缩包 27,289,600 字节；解压后 27,284,266 字节 | 解压后 3 个 | .NET 8 Desktop Runtime |
| `NebulaLauncher-v1.1.1-win-x64-portable.exe` | 自包含 + 单文件 + 裁剪压缩 | 25,590,875 字节（单文件，无解压步骤） | 1 个 | 无 |

zip 解压后 3 个文件：`NebulaLauncher.exe` 16,065,178 字节 + `libSkiaSharp.dll` 9,414,216 字节 + `libHarfBuzzSharp.dll` 1,804,872 字节。

- **zip**：解压到任意可写目录，双击 `NebulaLauncher.exe`。目标机缺 .NET 8 Desktop Runtime 时 Windows 会提示安装；装好后不需要 `%TEMP%` 写权限。
- **portable exe**：放到任意目录双击，无需解压、无需运行时。首次启动把原生库解压到 `%TEMP%\.net\NebulaLauncher\`；该目录被安全软件或策略拦截时启动会直接失败，改用 zip，或设置环境变量 `DOTNET_BUNDLE_EXTRACT_BASE_DIR` 指向一个可写目录。
- 两种形态共用同一份数据目录（默认 `%APPDATA%\NebulaLauncher`），可直接覆盖旧版使用；已保存的皮肤站账号与皮肤库不受影响。
- 可执行文件未签名，Windows SmartScreen 会弹「已保护你的电脑」：点「更多信息」，再点「仍要运行」。
