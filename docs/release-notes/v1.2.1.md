# Nebula Launcher v1.2.1

v1.2.0 之后的修复版，2026-11-02 发布。修掉皮肤站云端衣柜「应用到皮肤站」在材质已存在于皮肤库时直接失败的问题（票 #63）。其余功能与 v1.2.0 相同。

## 一、概览

**票 #63：网络皮肤“应用到皮肤站”复用重复 tid 时未校验衣柜归属。**

背景：网络皮肤卡片点「应用到皮肤站」时，启动器先把 PNG 上传到皮肤站。若这张 PNG 已经在站点皮肤库里，`POST /texture` 返回 `code: 2` 和已有 `tid`，表示“没有重复上传”；但该 `tid` 不一定在当前账号的衣柜里。旧逻辑拿到 `tid` 后直接 `PUT /user/player/{pid}/textures`，站点返回 `user.closet.remove.non-existent`（「衣柜中不存在此材质」），云端衣柜也看不到这张材质。

本版改为按站点语义补全链路：

- 重复材质先 `GET /user/closet/ids` 确认是否已在当前账号衣柜；已在则直接应用，不发多余请求。
- 不在衣柜时先 `POST /user/closet`（`{tid, name}`）把材质收藏进衣柜，成功后再 `PUT` 到角色。
- 收藏会按站点规则扣除积分（LittleSkin 为每件 10 积分）；界面在加入衣柜时明确提示，成功后也保留扣费说明。收藏失败则不应用，并原样给出站点原因与可操作提示。
- 应用成功后刷新云端衣柜列表（仅在已加载、第一页、皮肤分类、无搜索时），并保留用户原先选中的材质；后台刷新遇到登录失效不会静默把界面切到未登录。
- 首次上传新材质同样会由站点自动加入衣柜并可能扣积分，成功文案一并提示。
- 失败日志补充 `tid`、服务端 `code` 与是否重复，便于后续排查。

主要改动：`src/NebulaLauncher.App/Skinning/CloudClosetClient.cs`（新增衣柜编号查询与收藏）、`src/NebulaLauncher.App/ViewModels/CloudClosetViewModel.cs`、`tests/NebulaLauncher.Tests/AppSkin_CloudClosetClientTests.cs`、`tests/NebulaLauncher.Tests/AppSkin_CloudClosetUploadApplyTests.cs`、`docs/research/littleskin-web-session-texture-write-contract.md`。修复提交 `e261999`。

**其他：** 仓库 `.gitignore` 增加 `tmp/`，任务临时脚本与日志不再出现在 `git status` 里。版本提交 `c4e2184`。

## 二、安装与体积

体积在本机 win-x64、Release 配置下由 `build.ps1 -Publish` 构建后实测（2026-11-02，发布号 `v1.2.1`）。数字随 .NET 运行时版本与构建机变化。

| 附件 | 形态 | 实测体积 | 文件数 | 前提 |
| --- | --- | --- | --- | --- |
| `NebulaLauncher-v1.2.1-win-x64.zip` | 框架依赖 + 单文件，原生库外置 | 压缩包 11,281,359 字节；解压后 27,350,826 字节 | 解压后 3 个 | .NET 8 Desktop Runtime |
| `NebulaLauncher-v1.2.1-win-x64-portable.exe` | 自包含 + 单文件 + 裁剪压缩 | 25,620,064 字节（单文件，无解压步骤） | 1 个 | 无 |

zip 解压后 3 个文件：`NebulaLauncher.exe` 16,131,738 字节 + `libSkiaSharp.dll` 9,414,216 字节 + `libHarfBuzzSharp.dll` 1,804,872 字节。本次 zip 用 `Compress-Archive` 以 deflate 打包，因此比按原样存储的旧包小。

- **zip**：解压到任意可写目录，双击 `NebulaLauncher.exe`。目标机缺 .NET 8 Desktop Runtime 时 Windows 会提示安装；装好后不需要 `%TEMP%` 写权限。
- **portable exe**：放到任意目录双击，无需解压、无需运行时。首次启动把原生库解压到 `%TEMP%\.net\NebulaLauncher\`；该目录被安全软件或策略拦截时启动会直接失败，改用 zip，或设置环境变量 `DOTNET_BUNDLE_EXTRACT_BASE_DIR` 指向一个可写目录。
- 两种形态共用同一份数据目录（默认 `%APPDATA%\NebulaLauncher`），可直接覆盖旧版使用；已保存的皮肤站账号、免密令牌与皮肤库不受影响。

## 三、已知限制

1. **自动收藏会扣站点积分。** LittleSkin 每收藏一件材质扣 10 积分，删除返还。启动器在「正在加入衣柜」和成功文案里都会提示；这是站点既有规则，不是启动器额外收费。
2. **真账号冒烟未完成。** 本版修复与离线测试均已完成，但「真实账号 → 重复 PNG → 自动收藏 → 应用 → 游戏内生效」这条链路没有在当前构建上人工跑过（本机无站点凭据）。若你遇到收藏被拒或应用仍报 `user.closet.remove.non-existent`，请把票 #63 的现象回帖补上。
3. **免密（OAuth）模式仍不能上传新材质、改衣柜或删除云端材质。** 这些操作只走账号密码的网页会话；界面按钮会禁用并说明原因。
4. **应用默认是测试模式。** 设备代码流白名单应用初始只允许创建者账号授权；其他用户要等站方解除测试模式。这是站点侧配置，不是启动器行为。
5. 沿用 v1.2.0 的其他限制，见 `docs/release-notes/v1.2.0.md` 第三节。
