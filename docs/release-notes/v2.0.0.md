# Nebula Launcher v2.0.0

界面层整体重制：七个一级入口、一套统一的设计令牌与控件层、12 页固定栅格、液态玻璃外观，浅色与深色两副面孔同源。功能仍是原来的功能——启动、版本、模组与资源、下载、账户、服务器、设置——但每一页的分层、行高、滚动边界和控件状态都被重新定死，并且有契约测试守着。

这一版的主要变化在**可见的部分**，所以升级后第一次打开会觉得陌生。

## 一、概览

### 1. 五层结构与七个入口

窗口从下到上固定为五层：窗口底渐变（L0）→ 背景副本（L1，整窗唯一）→ 玻璃承载（L2，外壳竖栏、页面主卡、浮层）→ 内容（L3，文字、图标、输入、列表行）→ 浮层（L4，对话框、Toast、下拉）。**只有 L2 是真玻璃**，并且必须透出 L1 的真实背景——所以 L2 只用三层复合的 `GlassPanel`，不接受半透明纯色卡冒充。

一级入口收敛为七个，固定在左侧 82 宽（窗口窄于 1120 时收成 68）的玻璃竖栏里：

| 入口 | 内容 |
|---|---|
| 启动 | 欢迎行 + 「继续游戏」大卡 + 实例库（框内滚动） |
| 版本 | 视图页签、搜索与筛选、列表 + 右侧 340 宽详情、结果条 |
| 内容 | 模组 / 资源包 / 光影包 / 数据包 / 皮肤五个页签，各自固定栅格 |
| 下载 | 概览条 + 可折叠参数栏 + 任务列表 + 结果条（进度不走弹窗） |
| 账户 | 账户卡 + 设备码提示 + 账户列表 + 离线账户 |
| 服务器 | 工具条 + 可隐藏新建表单 + 服务器列表 + 导入结果条 |
| 设置 | 单层页签：常规 / Java / 游戏 / 下载 / 外观 / 存储 / 关于 / 日志 / 帮助 |

### 2. 双主题与统一令牌

所有颜色、圆角、字号、间距、控件高度、动效时长都走令牌：新增一个令牌要在 Dark 与 Light 各写一次，页面里**不写任何字面量**（颜色、字号、圆角、时长都不许）。这是本版最容易被后续改动破坏的约束，因此做成了契约测试——12 个页面 + 外壳任何一处写死字面量，测试立即失败。

- 强调色：浅色 `#1668FF`，深色 `#E80018`（黑主色 + 红强调）
- 品牌形象色 `#B53131`
- 圆角 8 / 12 / 16 / 20 / 24 / 28，胶囊 999
- 字号九档 11 / 12 / 13 / 15 / 17 / 20 / 26 / 29 / 38，正文 13
- 间距 4 / 8 / 12 / 16 / 20 / 24 / 32 / 40
- 控件高度 32 / 36 / 44
- 动效四档 90 / 150 / 220 / 320 ms，缓动 `cubic-bezier(.22,.9,.24,1)`

字体：中文用安托圆黑，英文与数字用 Mojang 风格字面。

### 3. 液态玻璃

玻璃的效果是「同源背景副本 + 模糊 + 半透明层 + 1px 亮边」：`GlassPanel` 把整棵背景子树复制一份并施加位图模糊 `blur(26px)` 与 `saturate(190%)`，再叠半透明层。这带来两点使用上的实际差异：

- 玻璃能看到**真实的**背景与背景图，不是一张灰色蒙版；
- 模糊是位图级的，窗口拖动或背景变化时不逐帧重算，代价可控。

### 4. 控件层与六态

按钮、输入、页签、列表行、开关、下拉、对话框等 14 类控件统一到一套模板，每一类都补齐 default / hover / focus / pressed / disabled / loading 六态。缺态按未完成处理。

### 5. 12 页固定栅格与三态

每页的行分配、固定列宽、紧凑档妥协方式都写死（正文内容随页面票落地）。两条硬约束：**固定列不参与拉伸**，**紧凑档只缩 `*` 列、不缩窄固定列**。

滚动边界同样定死：页面根不许是 `ScrollViewer`，固定区（外壳、TitleBar、首行工具条、底部结果条）在任何滚动下都不动，滚动必须有玻璃框、滚动条出现在框内侧。

空空如也、加载中、出错这三种状态在每页的同一位置补齐，空态必须给出下一步动作，而不是一段说明文字。

| `NebulaLauncher-v2.0.0-win-x64-portable.exe` | 单文件自解压 | 27,959,724 字节（约 26.7 MB） | 1 | 同上；首次启动需要 `%TEMP%` 可写 |

| 文件 | 字节 |

两种形态用法：

- **zip**：解压到任意目录，双击 `NebulaLauncher.exe`。整个文件夹可以随 U 盘搬走。
- **portable.exe**：直接双击，首次启动会解包到 `%TEMP%\.net\NebulaLauncher`。若被杀毒软件拦截解包，改用 zip 形态。

两种形态共用同一个数据目录 `%APPDATA%\NebulaLauncher`，从 1.x 升级过来不需要迁移，账户、实例、设置都在原地。

## 三、已知限制

1. **可执行文件未签名。** Windows SmartScreen 可能提示「已保护你的电脑」：点「更多信息」，再点「仍要运行」。
2. **玻璃没有跨元素实时背景模糊。** Avalonia 11.3 不提供 CSS `backdrop-filter` 那样的能力，玻璃靠「复制背景子树 + 位图模糊 + 半透明层 + 1px 亮边」实现。因此玻璃卡必须挂在能访问同源背景的位置；脱离这套结构的自绘卡片做不出同样的效果。
3. **旧的世界入口已并入实例详情，但旧视图文件还在树里。** 世界与整合包现在是实例详情右侧面板的两个分区；`WorldsView` 相关文件已无导航键可达，属于待清理的死路径，不影响使用。清理会单独提交，不与功能改动混在一起。
4. **资源库视图仍不可达。** 皮肤页已接入真实页面（`--page skins` 落到皮肤页）；`LibraryViewModel` 还没有接进导航，从导航进不去。
5. **列表行、详情列、参数卡这类内容区（L3）保持实心，不玻璃化。** 这是刻意的：玻璃只用在 L2 承载层，内容区再套一层玻璃会触犯分层契约，也会拖慢长列表滚动。若你看到某块内容区是实心白/黑卡，那是设计意图，不是漏做。
6. **本版是界面重制，功能集与 1.2.2 基本一致。** 1.2.2 遗留的皮肤相关限制（本地 slim HD 导入、皮肤站披风入口等 #65–#68 项）未进入本版，见 `docs/release-notes/v1.2.2.md` 第三节。
7. **浅色与深色逐页人工验收尚未全量做完。** 自动测试与发布产物自检已覆盖结构与契约；浮层遮罩做过双主题截图对照，其余页面若发现像素级出入，请在对应页面票补现象与截图。
