# Nebula Launcher v1.2.2

v1.2.1 之后的皮肤预览修复版，2026-11-02 发布。修掉 #64 的 3D 预览问题：默认皮肤、HD 皮肤 UV、特定角度顶面缺失及 HD 边缘黑线；其余功能与 v1.2.1 相同。

## 一、概览

**票 #64：皮肤 3D 预览纹理错位、错色、缺块，默认皮肤为手绘，特定角度顶面不渲染。**

- 默认皮肤不再逐像素手绘，改用 Mojang 官方客户端 1.21.5 的 Steve/Alex 64×64 纹理；账户头像与 3D 预览共用 Core 嵌入资源。
- 修正 UV 展开：身体与四肢侧面宽度取 `depth`（此前误用 `width`），修复所有皮肤的身体右/背面与 slim 手臂错位。
- HD 皮肤按实际纹理宽度整体缩放 UV：64/128/256/512 均按比例采样；128×64 老布局也能识别。此前 128 及以上纹理只取左上角 64×64。
- 顶面剔除改用减去 `OrbitCenterY` 的轨道坐标：相机刚高于头顶（约 pitch 15°）时不再把顶面整面丢弃。
- 光栅加固：纹素中心采样、共享边 1e-6 容差、1/w 深度缓冲、半透明 source-over 正确归一，降低 HD 皮肤棱角黑线与面缝。
- 测试新增 UV 64/128/512、顶面 pitch=15、HD 采样等断言；全量 2824/2824 通过。
- 修复提交：`daf6b7f`（UV/默认皮肤）、`9781c31`（HD UV）、`3fb7c58`（顶面/光栅）。

## 二、安装与体积

体积在本机 win-x64、Release 配置下由 `build.ps1 -Publish` 构建后实测（2026-11-02，发布号 `v1.2.2`）。数字随 .NET 运行时版本与构建机变化。

| 附件 | 形态 | 实测体积 | 文件数 | 前提 |
| --- | --- | --- | --- | --- |
| `NebulaLauncher-v1.2.2-win-x64.zip` | 框架依赖 + 单文件，原生库外置 | 压缩包 11285750 字节；解压后 27355946 字节 | 解压后 3 个 | .NET 8 Desktop Runtime |
| `NebulaLauncher-v1.2.2-win-x64-portable.exe` | 自包含 + 单文件 + 裁剪压缩 | 25622738 字节（单文件，无解压步骤） | 1 个 | 无 |

zip 解压后 3 个文件：`NebulaLauncher.exe` 16136858 字节 + `libSkiaSharp.dll` 9414216 字节 + `libHarfBuzzSharp.dll` 1804872 字节。本次 zip 用 `Compress-Archive` 以 deflate 打包。

- **zip**：解压到任意可写目录，双击 `NebulaLauncher.exe`。目标机缺 .NET 8 Desktop Runtime 时 Windows 会提示安装；装好后不需要 `%TEMP%` 写权限。
- **portable exe**：放到任意目录双击，无需解压、无需运行时。首次启动把原生库解压到 `%TEMP%\\.net\\NebulaLauncher\\`；该目录被安全软件或策略拦截时启动会直接失败，改用 zip，或设置环境变量 `DOTNET_BUNDLE_EXTRACT_BASE_DIR` 指向一个可写目录。
- 两种形态共用同一份数据目录（默认 `%APPDATA%\\NebulaLauncher`），可直接覆盖旧版使用；已保存的皮肤站账号、免密令牌与皮肤库不受影响。

## 三、已知限制

1. **本地皮肤库的 slim 仍只接受 64×64。** 普通 64×64/128×128 皮肤预览正常；slim HD 的本地导入尚未放开，需要单独改 `LocalSkinFormat`。
2. **本版只修 #64，不含界面调整。** 预览卡放大、底部说明删除、OAuth 首屏优化、皮肤站披风入口已分别拆到 #65–#68，未进入本版。
3. **按报告人要求未做 UI 人工验收。** 代码侧与自动测试、发布产物自检已完成；若实际界面仍有特定皮肤/角度异常，请回到 #64 补现象与展开图。
4. **可执行文件未签名。** Windows SmartScreen 可能提示「已保护你的电脑」：点「更多信息」，再点「仍要运行」。
5. 沿用 v1.2.1 的其他限制，见 `docs/release-notes/v1.2.1.md` 第三节。
