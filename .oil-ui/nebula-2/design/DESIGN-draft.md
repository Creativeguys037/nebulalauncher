# Nebula Launcher 设计规范（草案）

更新：2026-11-05
状态：**草案**，出自 #70（父地图 #69），交 `/to-spec` 前不落到产品代码。
取值表见同目录 `tokens.md`，控件定义见 `control-matrix.md`。

## 方向

现代液态玻璃，两副面孔、一套结构：**浅色 = 蓝白玻璃**（浅蓝底、白承载、黑副色），**深色 = 黑红玻璃**（近黑底、红强调、白副色）。参照 macOS 26 的玻璃面板层次，不做玻璃拟态的炫技。

## 品牌资产（不动）

- 品牌形象色 `#B53131`：跨主题保留，用于品牌装饰、渐变尾、次级强调（用户确认）
- 线性 SVG 图标：24×24 视口、圆头、统一线宽（用户确认）
- 玻璃层次语言：半透明层 + 1px 亮边 + `inset` 顶亮线与底内阴影（用户确认）

## 工作系统契约

1. **对象与任务**：对象是「实例」（版本 + 加载器 + 隔离目录）、「内容」（模组/资源包/光影/数据包/皮肤）、「世界」。主任务是「继续玩」与「管理实例」。判断依据：实例名、版本、加载器、上次游玩、运行状态。
2. **范围与导航**：左侧 7 入口图标栏——主页 / 版本 / 内容 / 下载 / 账户 / 服务器 / 设置。主页只承载「继续游戏 + 最近实例」；世界与整合包归版本详情；账户页只做账户。
3. **骨架与密度**：主视口 1240×800，最小 1024×660。首屏必须同时看见当前实例、至少 4 行实例、主行动。列表用 `ListBox` + 固定行高，详情用伴随面板或整页，阻断决定才用 Dialog。
4. **视觉表达与变量**：色彩身份见「主题」；八类语义角色落到 `Themes/Tokens.axaml` 的双字典。主要对比在「黑/蓝底 ↔ 玻璃层 ↔ 红/蓝主行动」三层之间，不靠给每张卡片换色。
5. **组件基础与状态**：Avalonia 原生控件 + `ControlTheme`；不引第三方 UI 库。每个控件定义 default / hover / focus / pressed / disabled / loading 六态，见 `control-matrix.md`。
6. **连续操作**：选实例 → 启动 → 进度与日志；版本页选实例 → 详情 → 内容/世界；切页保留筛选与滚动位置；关闭详情回到原选中行。

## 主题

两套主题**结构完全一致、色彩身份不同**（用户确认）：

| | 浅色 | 深色 |
|---|---|---|
| 身份 | 蓝白玻璃 | 黑红玻璃 |
| 主色 | `#1668FF` | `#E80018` |
| 形象色 | `#B53131` | `#B53131` |
| 承载 | 白 | 黑（主色）与白（副色） |
| 玻璃 | 白 34%→19% 半透明 + 亮边 | 红 6% 半透明 + 红 18% 描边 |
| 底色 | `#E8F0FF → #8FB4FF` 152° 渐变 | `#0A0205 → #1A0810` |

**深色以黑为主色**（用户确认）：红只出现在导航选中、主行动、进度三处；内容卡片保持黑底白描边，不铺红。禁止整屏泛红。

## 语义角色

变量在 `Themes/Tokens.axaml`，这里只写用途与限制；取值见 `tokens.md`。

- `Surface.Base` / `Canvas`：窗口底 / 内容区底。浅色是渐变底，深色是近黑。
- `Surface.Card` / `Raised` / `Glass`：卡片、浮起层、玻璃层。深色的玻璃层才带红。
- `Surface.Hover` / `Pressed` / `Sunken`：交互态与输入槽。
- `Text.Primary` / `Secondary` / `Tertiary` / `Muted`：四档文字。`Muted` 只做装饰与禁用，不作正文。
- `Text.OnAccent` / `OnBrand`：压在主色/品牌色上的文字。
- `Stroke.Subtle` / `Default` / `Strong` / `Focus`：分隔、控件边界、强调边界、键盘焦点。
- `Accent.Primary` / `Brand` / `Soft` / `Glow`：主行动与选中、品牌装饰、选中底色、辉光。
- `Status.*`：状态语义，配 `.Soft` 做底。**危险永不仅靠颜色表达**：必须带图标或文案。
- `Glass.*`：玻璃层的 tint / edge / topLight / innerShadow / shadow 五个角色。
- `Shadow.*`：卡片、悬停、浮层、辉光；平面分组不用重阴影。
- `Motion.*`：时长与缓动，C# 侧 `Motion.cs` 是唯一源。

## 字体与数字

- 界面字体：`Microsoft YaHei UI` 优先，回退 `Segoe UI` / 系统无衬线。
- 字号九档：11 / 12 / 13 / 15 / 17 / 20 / 26 / 29 / 38；正文用 13（用户确认，原 14 全线下调一档）。
- 字重四档：Normal / Medium / SemiBold / Bold。
- 数字：版本号、大小、进度、时间戳用等宽（`Cascadia Code` / `Consolas`），右对齐；正文不用等宽。

## 形状与空间

- 间距 4 的倍数：4 / 8 / 12 / 16 / 20 / 24 / 32 / 40。
- 圆角六档（用户确认归整到 4 的倍数）：8 标签与 ToolTip · 12 列表行与输入 · 16 按钮 · 20 卡片 · 24 浮层与 Dialog · 28 hero 与大卡；胶囊 999。
- 控件高度三档：32 紧凑 / 36 常规 / 44 主行动。
- 嵌套圆角递减：外层 28 时内层 20，外层 20 时内层 12。

## 动效

- 时长四档：90 按下 / 150 hover / 220 状态切换 / 320 页面转场。
- 缓动统一 `cubic-bezier(.22,.9,.24,1)`（快出慢收）。
- 只动 `Opacity`、`Background`、`BorderBrush`、`RenderTransform`；不动 `Margin`/`Padding`/大范围 `Width`。
- `Motion.Enabled = false` 时全部归零，循环动画一并停止。
- XAML 侧用 `{x:Static services:Motion.Fast}` 取 `TimeSpan`，不写死 `0:0:0.15`。

## 可用组件

- 基础：Avalonia 原生控件 + `Themes/Controls.axaml` 样式 + `ControlTheme`（仅 C 档控件重写）。
- 图标：`Themes/Icons.axaml` 的 `StreamGeometry`，命名 `Icon.<语义>`，尺寸 16/20/24，线宽 1.8。
- 容器：`Border.card` / `Border.glass` / `Border.sunken` / `Border.badge`。
- 完整矩阵（尺寸、六态、A/B/C 档）见 `control-matrix.md`。

## 不要做

- 不承诺 `backdrop-filter` 式实时背景模糊：Avalonia 11.3 有 `BlurEffect`，但它只模糊元素自身的绘制结果，不读取背后的兄弟内容。玻璃的做法是「同源背景副本 + `BlurEffect` + 半透明层 + 亮边 + 内阴影」；blur 只挂在副本那一层，卡片的文字与边框在它上面。
- 不用第二主色：浅色只蓝，深色只红；品牌色 `#B53131` 是装饰，不是第二强调。
- 不用纯黑 `#000000` 铺底、不用纯白大面积文字块。
- 不在页面写颜色字面量、字号字面量、圆角字面量、时长字面量。
- 不用红色单独表示危险；不把删除做成主行动的样式。
- 不引第三方 UI 库、图标字体、新 NuGet 包。
