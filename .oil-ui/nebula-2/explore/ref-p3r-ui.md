- 票：#72（父地图 #69）
- 素材：用户提供录屏 `屏幕录制 2026-11-05 141845.mp4`（1924×1082 / 30fps / 1分39秒）
- 分析方式：MiMo 视频理解，原画质 `-c copy` 分 4 段（每段 25 秒，`fps=2`、`media_resolution=max`），逐段结构化拆解

- 性质：这是**参考**，用于校准「P3R 蓝」方向的数值与结构；不复制其角色、文案、美术素材与品牌资产

## 1 录屏里出现的界面（全清单）

| 组 | 界面 |
|---|---|
| 枢纽 | 主命令菜单（SKILL / ITEM / EQUIP / PERSONA / STATUS / QUESTS / COMMU / CALENDAR / SYSTEM，纵向大字） |
| 队伍类 | 技能面板、道具面板、装备总览、装备详情、装备部位选择浮层、人格面具列表、面具详情浮层、状态 |
| 社交类 | 委托列表、社群列表、社群详情浮层 |
| 系统类 | 日历（含 JOB 侧栏）、系统菜单（TUTORIAL / CONFIG / DICTIONARY / DATA LOAD / DATA SAVE / ROLLBACK / RETURN TO TITLE）、教程目录与详情、设置（游戏系统 / 音频 / 图像 / 显示 / 键位）、用语辞典、存档槽列表、回滚槽列表、INFO 确认弹窗 |

**结论**：参考 UI 是「一个枢纽页 + 十来个同构三栏页 + 若干浮层」，不是卡片式后台，也不是侧边栏后台。

## 2 结构母题（最该抄的部分）

1. **斜切贯穿一切**：菜单项、列表条带、选中色块、页面转场遮罩，统一沿 **10–20°** 斜切轴；圆角恒为 **0**，全部直角斜切。
2. **三栏同构**：左栏列表（约 0–46%）＋ 右栏内容（52–96%）＋ 右下详情块（62–96% × 68–82%）；顶部 0–10% 是幽灵标题与页签。
3. **巨型幽灵标题**：约 64px、浅灰蓝 `#B9C6E8` @ 35%，压在背景上；真实标题常以更大字号被裁边出血。
4. **编号体系**：行首编号（01–09）或塔罗编号，等宽、低对比，始终在左。
5. **英文全大写小标签 + 中文正立正文**：英文/数字斜切，中文不倾斜，形成「斜体英文 + 正立中文」的反差节奏。
6. **条带与色条**：选中行整条反白或红底 + 左端 6–8px 彩色竖条 + 右移 8–12px。
7. **极低信息密度**：主菜单 9 项、一屏 7–9 行列表，大量负空间。

| 纯白 | `#FFFFFF` | 正文、主标题 |

| 层级 | 字号 | 字重 | 特征 |
|---|---|---|---|

## 5 控件与状态

- **菜单项**：平行四边形（斜切 10°），无填充；选中 = 红 `#FF2D4A` 填充 + 白色斜切小旗/三角尾 + 整条右移 8px，文字反白。
- **列表行**：行高 62–78px；左端 6–8px 彩色主题竖条；左 40–56px 方形头像/图标；选中整条反白或红底。
- **页签**：`◄ Q ｜ 中文标签 ｜ E ►` + 4 点分页指示，当前点亮白、其余 `#8FA2D6`。
- **徽章**：`NEW` 红底白字斜切小标签，约 62×22px，倾斜同主轴。
- **按键提示**：圆角 3px 键帽（白描边 + 深蓝内填），字 12px。
- **图标**：面性扁平双色为主，辅助线性箭头线宽 3px；不用图标字体。
- **属性条**：高 10px，青 `#22E0FF` 填充、深蓝底槽、右端数字右对齐。

## 6 动效

| 场景 | 形态 | 时长 |
|---|---|---|
| 换屏 | 白/青液态色块沿斜切轴扫屏（自右上向左下） | ~350ms |
| 面板进入 | 左栏自左滑入、右栏自右滑入，逐行 30ms 错峰 | 180–250ms |
| 列表选中 | 色块自左向右 wipe 擦入 + 红色侧条弹出 + 8–12px 位移 | ~120ms |
| 主菜单选中 | 文字轻微放大（1.0→1.02）+ 红斜条滑入 | ~150ms |
| 详情浮层 | 立绘右侧切入，属性条 0 宽横向拉伸填满 | ~400ms ease-out |
| 背景 | 水波焦散缓慢流动（2 层不同速率、视差） | 8s 循环 |
| 弹窗 | 中心淡入 + 上移 8px | ~200ms |

**明确没有**：不透明度整页渐隐、卡片缩放弹入、弹性滚动、星云粒子。

## 7 迁移到 NebulaLauncher 的规则

**要抄**：斜切轴与 0 圆角、三栏同构、幽灵标题、行首编号、全大写小标签、等宽右对齐数值、选中态反白/红底 + 位移、极低密度、斜切扫屏转场。

**不抄**：角色立绘、塔罗/人格面具语义、游戏内文案与图标、满屏水波插画、日文招牌。

**落地换算（1240×800 视口）**：主菜单项 52px → 30–34px；幽灵标题 64px → 88–110px（出血裁边）；列表主文 22px → 17–18px；数值 20px → 13px 等宽；小标签 11px → 9–10px；行高 78px → 56–60px；斜切 10° → `skewX(-8°)` + 按钮 `clip-path` 16px。
