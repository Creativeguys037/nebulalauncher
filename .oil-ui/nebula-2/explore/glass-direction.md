## 一句话

浅蓝底上浮一层半透明玻璃：蓝是唯一主色，白负责承载与提亮，黑只做文字与一块深色锚点。圆角大、边缘有亮边、背景色块在玻璃下被糊开。

## 六项

### 1 调性
现代、清透、有厚度。像 macOS 26 的玻璃面板，不像玻璃拟态的炫技稿，也不像扁平的 Web 后台。
关键词：glass / translucent / bevel / soft-shadow / airy。反面：像素、斜切、重投影、霓虹、紫色渐变。

### 2 字体
`system-ui / -apple-system / Segoe UI / 微软雅黑`。标题 38px/800（小窗 26–29px），正文 13px，元信息 10.5–11px，机器可读数字用等宽 `ui-monospace`。不用全大写斜体小标签（那是上一版 P3R 的语言，本方向不沿用）。

### 3 色彩
| 角色 | 值 | 用途 |
|---|---|---|
| 主蓝 | `#1668FF` | 主行动、选中、进度、图标 |
| 深蓝 | `#0B3FCC` | 主蓝渐变尾、按下态 |
| 辅助青 | `#37D6FF` | 背景光斑、进度渐变尾 |
| 白 | `#FFFFFF` | 玻璃层、卡片、主按钮字 |
| 黑 | `#0A0D14` | 正文文字、唯一深色块、次要按钮文字 |
| 灰蓝 | `#39445A` / `#6B7891` | 次级/弱文字 |
| 底色 | `#E8F0FF → #C9DCFF → #A8C6FF → #8FB4FF` | 页面背景（152° 渐变） |

面积比：蓝白约 9 成，黑只在文字与右下状态卡。**不用**第二主色，不用紫色。

### 4 密度
4px 栅格，卡片圆角 28/20/14，内边距 15–28，块间距 12–16。一屏 1 个 hero + 4 张小卡 + 3 块信息，信息密度低。

### 5 图标
24 视口线性 SVG，`stroke-width 1.7–1.9`，圆头；选中态反白压在蓝色胶囊上。不用面性彩色图标、不用 Emoji、不用图标字体。

### 6 动效
- hover：卡片上浮 3px + 阴影加深，160ms `cubic-bezier(.22,.9,.24,1)`
- 按钮：上浮 1px + 阴影扩散，150ms
- 导航：背景色淡入 + 图标，160ms
- 不做：整页位移转场、粒子、视差滚动

## 玻璃规格（这份方向的技术核心）

页面上没有真实可模糊的内容，`backdrop-filter` 在部分渲染环境里也不生效，所以采用**同源背景内衬**：

1. 页面背景收在一个 CSS 变量 `--bg-layers` 里：3 个硬边圆形色块 + 4 个柔光 + 1 个 152° 线性渐变。
2. 每个玻璃元素用 `::after` 铺同一份 `--bg-layers`，`background-attachment: fixed` 保证与视口对齐，再 `filter: blur(26px) saturate(190%)`。
3. 玻璃元素本身底色透明，`::before` 叠一层白（上 34% → 下 19%）+ 左上角高光斑。
4. 边缘：`1px rgba(255,255,255,.86)` 描边 + `inset 0 2px 0 #fff` 顶亮线 + `inset 0 -16px 30px -16px rgba(16,48,120,.28)` 底内阴影。
5. 外投影：`0 26px 60px rgba(16,48,120,.22)`。

**为什么这样做**：硬边色块是给玻璃「可被模糊的内容」，如果没有它们，玻璃压在同色背景上读不出边界；同源副本保证模糊后的颜色与位置都对得上，不依赖 `backdrop-filter` 的实现差异。

## 连续操作

1. 首页选实例 → 启动 → 顶部状态胶囊转「启动中」+ hero 主按钮 loader → 进入运行态（可停止）。
2. 首页「编辑实例」→ 版本页该实例详情 → 改内存/Java → 保存回首页，列表行元信息同步刷新。
3. 版本页页签切换（已安装/可下载/整合包）保留筛选与滚动位置；选中行变更时右栏详情跟着换，列表不重排。
4. 关闭详情/切页返回列表，落回原选中行与滚动位置。
5. 下载任务进行中：右侧下载卡实时更新百分比，完成后该行淡出并让位。

## 实现注记（Avalonia 端，2026-11-05）

方向卡是 HTML 视角，落到 Avalonia 11.3 有三处必须换算：

1. `backdrop-filter` 没有对应物。用的是「同源背景副本」：把页面的渐变与硬边色块抽成可复制的一层，按玻璃元素位置做同样偏移放进元素内部，只对这一层挂 `BlurEffect`（`Radius=26`），文字与边框压在它上面。
2. `saturate(190%)` 无内建。用一层淡蓝（浅色）/ 淡红（深色）叠加近似饱和感，或接受饱和度不变。
3. `inset 0 2px 0 #fff` 在 Avalonia 解析失败，必须写 `inset 0 2 0 #fff`；其余阴影数值同样不带 `px`。

完整证据与控件边界见 `docs/research/avalonia-glass-controls-20261105.md`。
