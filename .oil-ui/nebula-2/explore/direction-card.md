# 方向卡：P3R 蓝 · 主菜单式工作台

- 票：#72（父地图 #69）
- 日期：2026-11-02
- 性质：oil-ui-pro 方向卡 + 工作系统契约；样张 `home-p3r-menu.html`，截图 `.oil-ui/nebula-2/shots/direction-p3r-menu/`
- 参考性质：**借鉴** P3R 的色彩关系与主菜单构图；结构参考 BakaXL / Axolotl 的「最近项目列表 + 信息栏」。不复制角色、菜单文案、游戏内图标或品牌 Logo。

## 一句话

蓝色是主色调，白是字，黑与红只做锚点与强调：钴蓝渐变底、白色粗斜体大标题、右侧纵向菜单、编号实例列表、青蓝主行动、黑底信息卡、左下大裁切字；首页就是一张可操作的 P3R 主菜单，不是卡片后台。

## 六项

### 1. 调性
- 蓝色海报感、现代、锐利、有节奏；像 P3R 主菜单，不像后台，也不像像素游戏。
- 关键词：blue-dominant / poster / italic / high-contrast / sharp。反面：dark SaaS、glassmorphism、pixel-retro、圆润糖果。
- 情绪目标：打开就被蓝色、白色大标题和「启动」抓住。

### 2. 字体
- 界面：`system-ui, "Microsoft YaHei", "PingFang SC", sans-serif`。
- 大标题 78px / 900 / italic / letter-spacing -5；当前实例 26px / 800 / italic；实例行 18px / 800 / italic；右侧菜单 31px / 900 / italic。
- 元信息与英文标签：`ui-monospace, "Cascadia Mono", Consolas, monospace`，9–11px，大写、0.08–0.28em 字距。
- 中文斜体用浏览器伪斜体，允许轻微变形以换取 P3R 的动势；正文不倾斜。

### 3. 色彩
| 角色 | 值 | 用途 |
|---|---|---|
| 主蓝 `--blue` | `#0269F6` | 背景主段、主结构 |
| 亮蓝 `--azure` | `#00A9F0` | 背景亮部、次级高光 |
| 青蓝 `--ice` | `#45F3FC` | 主行动、当前项、进度、关键高光 |
| 深蓝 `--deep` | `#273C62` | 背景暗部、面板 |
| 蓝底渐变 | `#0B5BE0 → #0A46C0 → #08328C → #273C62` | 大面积主背景 |
| 白 `--white` | `#FCFDFD` | 主文字、大标题、菜单 |
| 近黑 `--ink` | `#05060A` | 只做锚点：信息卡、按钮字、裁切装饰字、阴影 |
| 暖红 `--red` | `#F25C4A` | 当前菜单项、极少量强调；P3R 的「粉红叠白」暖红，不用纯红 |
| 暖红高光 `--red-warm` | `#FF8A70` | 红色竖条渐变、白描边旁的高光 |

- 大面积必须是蓝；白色负责信息；近黑与红色只占小面积。
- 同一屏只有一个青蓝主行动；当前菜单项用红色文字 + 6px 红色竖条。
- 不用紫色、不用大面积白色卡片、不用渐变白底。

### 4. 密度
- 4px 子网格、8px 主网格；页面边距 28/26；主区宽 760，右侧菜单 260。
- 斜切：16px 主按钮平行四边形；列表行左侧 3px 红/青蓝竖条；信息卡直角黑底。
- 控件高度：44（菜单行）/ 54（实例行）/ 52（主行动）。
- 圆角：0（P3R 硬边）；不用大圆角卡片。
- 阴影：仅主按钮青蓝辉光、红色竖条辉光；其余靠蓝底层差与 1px 白描边。

### 5. 图标
- 24×24 视口，SVG path，`stroke-width: 1.6–1.7`，圆头圆角。
- 线性、统一线宽；当前项用青蓝/红色，不填充整块。
- 不用字母块、Emoji、图标字体、像素图标。
- 身份素材：账户头像用真实皮肤头像；实例图标用加载器/版本类型几何图标；模组图标用真实项目图标。

### 6. 动效
- 微交互：140ms `cubic-bezier(.2,.8,.2,1)`；菜单项 hover 变青蓝 + 左移 5px；实例行 hover 右移 5px + 白 10% 底；主按钮 hover 亮度 + 右移 4px。
- 页面/列表转场：240ms 淡入 + 上移 6px；列表逐项延迟 18ms，最多 5 项。
- 状态反馈：进度条 300ms 以上；成功/失败 160ms 淡入，不弹跳。
- 装饰动画：背景斜向光带可缓慢漂移（10s 循环），默认关闭或减少动效时关闭；不做星云粒子。
- 所有时长走 `Motion.Dur`；`Motion.Enabled=false` 时归零。

## 工作系统契约（oil-ui-pro 六项）

1. **对象与任务**：对象是「实例」（版本 + 加载器 + 隔离目录）、「内容」（模组/资源包/光影/数据包/皮肤）与「世界」（实例内存档）；主要任务是「继续玩」与「管理实例」。判断依据：实例名、版本、加载器、上次游玩、运行状态。
2. **范围与导航**：右侧纵向菜单 7 入口：主页 / 版本 / 内容 / 下载 / 账户 / 服务器 / 设置；主页 = 大标题「继续游戏」+ 当前实例 + 编号实例菜单 + 青蓝主行动 + 右侧菜单；版本页 = 实例列表与详情（实例详情内含世界/存档、整合包导入导出）；内容页 = 模组/资源包/光影包/数据包/皮肤 Tab；账户页只做账户；设置含日志与帮助。世界不得与整合包混在同一分类。
3. **骨架与密度**：1240×800 主视口，1024×660 最小视口；右侧菜单固定 260/200px；主区 760/600px；首屏必须看见当前实例 + 至少 4 行实例 + 主行动；1024×660 下隐藏第 5 行实例并压缩行高，保证不裁切。
4. **视觉表达与变量**：见上方六项；所有颜色/字号/间距/斜切尺寸走 CSS 变量（落地时对应 Tokens.axaml 的 Light/Dark 双字典）。
5. **组件基础与状态**：Avalonia 原生控件 + 自定义样式；Button（primary/row/menu/icon/danger）、TextBox、ComboBox、CheckBox、ToggleSwitch、ListBox 行、Tab、ToolTip、Dialog；每个组件定义 default/hover/focus/pressed/disabled/loading 六态。
6. **连续操作**：从主页选实例 → 启动 → 进度/日志；从版本页选实例 → 详情 → 内容/世界；切换页面保留筛选与滚动位置；关闭详情回到列表原位置。

## 与现状的三处结构差异

1. **视觉方向彻底换**：从深空星云玻璃 → P3R 蓝色主菜单（蓝底、白粗斜体、红/青蓝锚点、黑底信息卡、大裁切字）；从 11 入口 → 7 入口；皮肤并入内容，世界与整合包归版本详情，账户页只做账户。
2. **首页从「卡片堆」变成「主菜单」**：大标题 + 当前实例 + 编号实例行 + 青蓝 CTA；账户/版本/统计不再重复；右侧纵向菜单承担导航。
3. **控件语言统一**：斜切 16px、行高 44/54、直角硬边、全部间距落 4px 网格；去掉 Fluent 默认 ToggleSwitch/ComboBox/TextBox 皮肤。

## 参考边界（不照搬）

- P3R：只取色彩关系（蓝主、白字、近黑/红锚点）、粗斜体菜单排版、斜切构图、编号/英文小标签的节奏；不复制角色、菜单文案或游戏内图标。
- BakaXL：借鉴顶部信息卡、右上账户、明亮底的组织感；不照搬蓝色背景图形。
- Axolotl：借鉴「从最近的项目开始」列表行 + 信息栏；不照搬日历、新闻、每日挑战。
- LauncherX：借鉴单一强品牌色的勇气；不照搬黄色满屏与底部导航。

## 保留的风格提示（截图 lint）

- 标题上方眉标、彩色单侧条：P3R 主菜单语言的一部分，保留（眉标只做 `CONTINUE` 一行，红色竖条只标当前项）。
- 无对比度 / 横向溢出 / 控制台错误。
